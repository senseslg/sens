## Jira 接入

复用 [jira-service](../wms-db/jira-service/README.md)，不复制其业务逻辑，不直接写 Jira 数据库。以下为该服务 2026-10-03 的文档快照，本轮未检查实时运行状态。

| 能力 | 现有方式及边界 |
|---|---|
| 创建 | `POST /requirements`，先查重及默认预检查；提交需幂等键，提交后读回。真实创建 CE-2629 已验证 |
| 关闭/不做 | 先读取 transitions，再调用 close 接口；需明确编号、原因、当前状态与解决结果。真实预检查通过，实际关闭尚未验证 |
| 查询与通用导出 | JQL 查询、汇总、CSV 自选字段或全部 API 字段；全部 API 字段不等于后台“所有域” |
| 周报/月报 | `POST /reports/resolved/export` 或 `export_report.py`，按解决日期导出固定 8 列；九月 152 条已有实测记录 |

报表列：问题关键字、概要、问题类型、经办人、已解决、报告人、创建时间、项目名称。默认时区 `Asia/Phnom_Penh`；日期区间含起始日、不含结束日，默认全部可见项目，可限定项目。

“已解决”来源为 Jira 解决日期，不验证实际部署时间，也不自动排除 Won't Do；重新打开并清空解决日期的问题不会入选。周报暂复用 8 列，尚未单独确认最终模板。

服务仅监听本机 `127.0.0.1:8765`，业务接口需 `X-API-Key`，不是常驻生产服务。导出最大 10000 条，截断拒绝生成；超时未知结果不能换幂等键盲目重试。完整操作及限制以 [服务 Runbook](../wms-db/jira-service/RUNBOOK.md) 为准。
