# CE Finance Roadmap

## Phase 0：确认边界

- [ ] 明确法律主体、业务范围和财务负责人。
- [ ] 明确本位币、使用币种、会计期间和时区。
- [ ] 明确管理银行、现金、支付平台和内部账户。
- [ ] 盘点现有 Excel、账单、业务系统和纸质凭证。
- [ ] 明确访问权限、审核职责和外部共享边界。

## Phase 1：建立账目基线

- [ ] 完成账户代号和账目分类。
- [ ] 设计结构化账目表和字段校验。
- [ ] 导入首批原始数据并执行去重。
- [ ] 确认期初余额和未结应收应付。
- [ ] 建立凭证索引和缺失凭证清单。
- [x] 建立 Plasgate 短信充值周期报销文案、计算和核对模板。

## Phase 2：首个月结

- [ ] 完成银行、现金和平台对账。
- [ ] 完成应收应付与账龄核对。
- [ ] 处理内部转账、退款、手续费和汇率差异。
- [ ] 输出首个月度摘要和异常清单。
- [ ] 由负责人审核并锁定期间。

## Phase 3：持续管理

- [ ] 建立每周未入账与逾期检查。
- [ ] 建立月结日历和负责人提醒。
- [ ] 建立预算与实际差异分析。
- [ ] 建立备份、恢复和访问审计。
- [ ] 评估从表格迁移到财务系统或数据库的条件。

## 自动化候选

只有在字段和流程稳定后才实施：

- 银行或平台 CSV 导入与字段标准化。
- 重复流水检测。
- 内部转账配对。
- 余额与月结单差异检查。
- 应收应付账龄计算。
- 月度汇总和异常报告生成。

自动化默认只读原始数据，输出新结果文件；不得硬编码网银、支付平台或数据库凭证。

## 当前下一步

请先提供以下信息：

1. 账目属于个人、公司还是多个主体。
2. 主要账户和使用币种。
3. 现有账目文件或系统的位置与格式。
4. 希望从哪个月份开始整理。
5. 是否需要管理应收应付、报销、工资、税务或库存。
