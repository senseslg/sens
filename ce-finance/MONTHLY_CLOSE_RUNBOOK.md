# Monthly Close Runbook

月结默认由录入人与审核人分工完成。未明确负责人前，本流程只作为待采用方案，不代表已经执行。

## 1. 冻结数据范围

- 明确关账主体、月份、本位币和时区。
- 收齐当月银行、现金、支付平台、业务系统和报销数据。
- 记录迟到数据和预计补录时间。
- 对原始文件创建只读备份，并限制访问范围。

## 2. 完整性检查

- 检查流水日期是否覆盖整个期间。
- 检查 Transaction ID、账户、币种、分类和金额是否完整。
- 检查重复流水、空金额、异常负数和不受控分类。
- 检查所有外币记录是否有汇率和本位币金额。
- 检查内部转账两端是否匹配。

## 3. 对账

| 对账项目 | 核对依据 | 完成标准 |
|---|---|---|
| 银行账户 | 银行月结单 | 账面余额与银行余额一致，未达项有明细 |
| 现金 | 现金盘点 | 实盘与账面一致，差异已批准处理 |
| 支付平台 | 平台结算报表 | 交易、手续费、退款和结算到账可追溯 |
| 应收账款 | 客户、订单和收款记录 | 余额与账龄清晰，逾期项有负责人 |
| 应付账款 | 供应商、采购和付款记录 | 余额与到期日清晰，无重复付款 |
| 报销与预支 | 申请、凭证和归还记录 | 未核销项目有负责人和截止日期 |
| Plasgate 短信 | 平台用量、账单、相邻充值记录和报销审批 | 充值周期消耗与未使用余额分开，金额、币种及较上次变化可复核 |

## 4. 异常处理

- 差异必须记录金额、币种、账户、发现日期、原因判断和负责人。
- 未查明差异不得用“其他收入/支出”直接抹平。
- 跨期、错币种、重复或漏记使用可追溯调整记录处理。
- 重大差异或疑似舞弊、错误付款应立即升级，不等待月结结束。

## 5. 月度输出

- 期初、期间发生额和期末余额。
- 收入与支出分类汇总。
- 应收应付余额与账龄。
- 现金流入流出摘要。
- 多币种余额与汇率影响。
- 未对账项目、缺失凭证和逾期行动项。
- 与上月、预算或业务数据的重大差异说明。

## 6. 审核与锁定

- 录入人完成自查。
- 审核人复核余额、抽查凭证和重大调整。
- 负责人批准月结摘要与未决事项。
- 将期间状态改为 `closed`，保存输出和审核记录。
- 后续更正使用调整记录，不静默改写已关闭期间。

## 月结检查表

- [ ] 所有账户数据已收齐。
- [ ] 银行、现金和平台余额已核对。
- [ ] 内部转账已双向匹配。
- [ ] 应收应付与账龄已复核。
- [ ] 外币与汇率记录完整。
- [ ] 缺失凭证和异常差异有行动项。
- [ ] 本关账期内发生的 Plasgate 支付，其用量、费用、充值余额和报销说明已核对（如适用）。
- [ ] 月度汇总经过审核。
- [ ] 期间已锁定并完成备份。
