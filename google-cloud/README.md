# google-cloud

Google Cloud 控制台管理子项目：保存项目级资源索引、管理边界、巡检入口和重要变化。当前已核实的项目为 `Cambodian Express`（`cambodian-express`）。

## 阅读顺序

1. [PROJECT_READ_FIRST.md](PROJECT_READ_FIRST.md)：开始和结束任务的规则。
2. [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md)：范围、状态和重点。
3. [RESOURCE_INVENTORY.md](RESOURCE_INVENTORY.md)：带日期的控制台资源快照。
4. [MANAGEMENT_RULES.md](MANAGEMENT_RULES.md)：变更、权限、费用和记录规则。
5. [RUNBOOK.md](RUNBOOK.md)：已核实的控制台入口与只读检查路径。
6. [PROJECT_ITERATION_LOG.md](PROJECT_ITERATION_LOG.md)：重要变化。
7. [TMS_DB_CAPACITY_REVIEW_2026-09-28.md](TMS_DB_CAPACITY_REVIEW_2026-09-28.md)：共享 Cloud SQL `tms-db` 的容量、表空间差额和优化顺序。

服务内部的部署与故障细节继续记录在仓库现有的 `google-otwms/`、`otwms-ce-lb/`、`otwms-wms-server/` 等子项目；此处维护 Google Cloud 项目级视角并链接到相关记录。
