## 目标

建立办公网络的长期管理记录，以 MikroTik 设备为核心，逐步覆盖资产、拓扑、配置基线、监控、备份和故障处理。

## 完成标准

- [x] 创建独立的 `office-network` 子项目和基础文档。
- [x] 完成 MikroTik 设备型号、RouterOS 版本和当前账号权限盘点。
- [ ] 记录脱敏后的端口、VLAN、网段和上联关系。
- [ ] 建立配置备份、变更验证和回滚规范。
- [ ] 明确监控指标、告警方式和日常巡检标准。
- [ ] 建立常见故障处理与恢复流程。
- [x] 建立公网端口映射的安全实施、验证和回滚流程。

## 范围

### 暂定包含

- MikroTik 交换机及相关 RouterOS 配置管理。
- 设备资产、端口、VLAN、网段和网络拓扑记录。
- 配置备份、升级、监控、巡检和故障处理。
- 经确认后的网络变更及验证记录。

### 暂不包含

- 未明确授权的生产配置变更。
- 密码、密钥、完整配置导出和其他敏感凭据。
- 办公终端和业务服务器自身的系统运维。

## 当前状态

项目已建立。办公网网关为 MikroTik RB3011UiAS，运行 RouterOS 6.49.1；当前 `admin` 账号可通过 WebFig 读写 NAT/Firewall，但不能管理用户或使用 SSH/API。办公网另有两台 VMware ESXi 主机，其中 `esxi-02` 已完成首轮只读基线。

## 风险与依赖

- 当前缺少设备和拓扑基线，不能判断单点故障、环路、配置漂移或版本风险。
- MikroTik 配置可能包含公网地址、账号、密钥和业务网络信息，采集与记录必须脱敏。
- 远程执行命令或修改配置前，需要明确只读/变更权限、维护窗口和回滚方案。
- 公网暴露会扩大攻击面；管理后台、数据库和调试服务应优先使用 VPN，Web 服务至少需要 HTTPS、认证和访问日志。
- WebFig 当前通过 HTTP 登录，管理会话缺少传输加密；在完成备份和兼容性评估前，不直接调整管理服务或升级 RouterOS。
